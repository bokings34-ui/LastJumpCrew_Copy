# PHS Network Generated Audio

- Authoring menu: `Tools/ParkHanSol/BEAVER/Author Network Generated Audio`
- Generator: `PHSNetworkGeneratedAudioAuthoring.cs`
- Sample format: 44,100 Hz, mono, PCM signed 16-bit WAV
- Normalization ceiling: -3 dBFS (`0.707945784` linear peak)
- Fixed seed: `20260723`, plus deterministic per-recipe offset `index * 7919`
- Runtime generation: none. `AudioClip.Create` is not used.

## Provenance and license boundary

All WAV files produced by this generator are original procedural audio. They use
only mathematical oscillators, envelopes, and fixed-seed pseudo-random noise.
No external recordings, samples, models, or generated-audio services are used.

Do not label these files as CC0 unless the project owner separately publishes
them under CC0. Project ownership and distribution terms apply.

`PHS_ZeroGravityThruster_CC0.ogg` is a separate third-party CC0 asset with its
own source and license note. `Sound_Fire.mp3` has no verified source/license note
and must not be referenced by the generated audio set or release prefabs.
